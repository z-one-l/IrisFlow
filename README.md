# IrisFlow

Online demo: <https://z-one-l.github.io/irisflow/>

The demo runs the trained model on a Hugging Face Space.

The code will be made available to editors and reviewers upon request during peer review, and will be publicly released upon publication at <https://github.com/z-one-l/IrisFlow>, with an archived version deposited on Zenodo under a persistent DOI. The trained model weights and the training and test datasets will be released on Hugging Face.
